# Security Evidence Matrix

This document maps the current institutional-readiness security claims to
executable evidence in the repository.

It is not an independent audit and it is not a production-ready statement. Any
row marked "covered locally" still requires clean checkout CI, live rehearsal,
and external review before publication. Mainnet production-ready claims are
forbidden; any future production-candidate wording must be testnet-scoped and
must link the complete testnet lifecycle, recovery, signer conformance,
security review, governance/key-rotation, benchmark, and final CI evidence,
technical addendum evidence, with the corresponding publication blockers
checked.

Row-local claim-allowed fields describe the evidence row only. They do not
authorize global release wording; the global release decision remains governed
by [Institutional Release Checklist](release-checklist.md).

## Status Legend

| Status | Meaning |
|---|---|
| Covered locally | There is executable local evidence for the current claim. |
| Guarded | The unsafe path is blocked by code/tests, but the final production path depends on upstream or operational evidence. |
| Pending rehearsal | Code or documentation exists, but a clean live run is still required. |
| Open blocker | Required for testnet production-grade claims and not yet implemented. |
